# Instagram Skills RU — Claude

Семь русскоязычных навыков для подготовки Instagram-контента. Ничего не публикуют, не просят пароли и не управляют комментариями или директом.

| Навык | Задача |
|---|---|
| `/ig-reel` | Сценарии Reels, хуки и тайминг на русском |
| `/ig-carousel` | Тексты и изображения каруселей на русском |
| `/ig-caption` | Подписи к постам с проверкой текста и призыва |
| `/ig-profile` | Оценка профиля и улучшение шапки Instagram |
| `/ig-viral` | Разбор роликов по просмотрам и формулам хуков |
| `/ig-plan` | План публикаций Instagram на неделю |
| `/ig-repurpose` | Переупаковка длинного материала в посты и Reels |

## Установка

Для Claude с поддержкой загрузки Skills используйте отдельные архивы в `dist/`: каждый содержит папку навыка с `SKILL.md`. Загрузите нужные ZIP по одному в разделе навыков и включите их. Названия разделов и доступность зависят от версии и тарифа Claude. Исходная инструкция прилагается в `KAK_USTANOVIT.md`.

Для Claude Code скопируйте нужные папки из `skills/` в `.claude/skills/` своего проекта или в `~/.claude/skills/` для личного использования.

Пример запроса: «Используй ig-reel: сценарий о трёх ошибках при выборе квартиры».

## Профиль голоса

Шаблон `golos_shablon.md` лежит в каждом навыке. Создайте из него общий `golos.md` для аккаунта и храните в своём проекте (для Claude — добавьте к материалам проекта). При первом запуске навык помогает заполнить его. Персональные данные, реальные планы и журнал публикаций не входят в этот репозиторий.

## Скрипты и проверки

Для скриптов нужен Python 3; сторонние библиотеки не требуются. `hookscore.py` оценивает хук, `beats.py` прикидывает тайминг, `caption.py` проверяет подпись, `swipe.py` ранжирует предоставленные данные. Это редакционные ориентиры, а не гарантия просмотров. Скрипты не собирают данные из Instagram.

Формат TSV для `swipe.py`: `account`, `followers`, `median`, `views`, `hook` через табуляцию. Числа записывайте полностью (`412000`, а не `412k`). Предпочтительна медиана просмотров; при её отсутствии скрипт использует подписчиков как приблизительную базу, что нельзя выдавать за медиану аккаунта.
