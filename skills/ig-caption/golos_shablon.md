# golos.md — профиль голоса для Instagram-навыков

Этот файл читают все навыки набора: /ig-reel, /ig-carousel, /ig-caption, /ig-profile, /ig-viral, /ig-plan, /ig-repurpose. Заполните его один раз (навык поможет, задавая вопросы по блокам) и держите в файлах проекта Claude или прикрепляйте к разговору.

Тексты в Instagram произносятся вслух. Фраза, которую вы никогда не скажете, — это не черновик, а лишний дубль. Поэтому отвечайте честно, как есть.

---

## 1. Общее: как я звучу (для всех аккаунтов)

- **Имя:**
- **В кадре я:** (быстрый / спокойный / ироничный / смешной / сухой / энергичный — можно несколько)
- **Как строю фразы:** (коротко / развёрнуто)
- **Слова и обороты, которые я правда говорю:**
- **Слова, которые я никогда не скажу вслух:** (например «друзья», «эксперт», «залетай»)
- **Мат:** (да / мягко / нет)
- **Эмодзи в подписях:** (никогда / одно-два / свободно)
- **Обращение к зрителю:** в ролике («ты» / «вы»), в подписи («ты» / «вы»)
- **Лицо в кадре:** (всегда / иногда / без лица)
- **Говорю в камеру или озвучка:** (в камеру / с телесуфлёром / озвучка)
- **Съёмка:** (сам на штативе / есть оператор / телефон в руке)
- **Темп речи:** (слов в минуту, если засекали; по умолчанию 150, быстрая речь ~170)
- **Длинное тире «—»:** (использую / не использую)

## 2. Аккаунт: @ник

Скопируйте этот раздел для каждого аккаунта.

- **О чём аккаунт, одной фразой:**
- **С кем говорю:** (конкретно: кто, чем занят, что болит)
- **Аудитория по статистике:** (пол, возраст, страны — из статистики Instagram, если есть)
- **Что продаю:** (продукт, цена, где купить — или «пока ничего»)
- **Доказательства, которые можно называть:** (опыт, цифры, клиенты, результаты)
- **Мои позиции:** (3–5 мнений, с которыми можно поспорить)
- **Тон:** (чем отличается от других моих аккаунтов)
- **Темы, о которых не пишу / что не показываю:**
- **Призыв:** (кодовое слово в комментариях → бот присылает подарок / сохранить / написать в директ / подписаться)
- **Если кодовые слова:** правило «одно слово на пост», какой сервис отвечает (ManyChat, SendPulse и т. п.)
- **Визуальный стиль обложек и каруселей:** (шрифт, цвета, фон, сколько строк на обложке)
- **Правила монтажа:** (safe zones, что нельзя закрывать графикой, что раздражает)
- **Примеры моих текстов, которые звучат как я:** (2–3 подписи или ссылки)

## 3. Рабочие записи навыков

- Журнал публикаций: `log.md` (дата, аккаунт, формат, формула хука, первая фраза, кодовое слово).
- Банк хуков: `swipe_{аккаунт}.md` (пишет /ig-viral). План недели: `plan_{аккаунт}.md` (пишет /ig-plan).
